# 商談アシスタント

Zoom 商談の会話をリアルタイムで文字起こしして、相手が話した困りごとから「その場で作れるツール」を提案します。
提案ごとにボタンが2つあります。

- **デモを自動生成**：AI が単一HTMLのデモツールを作り、新しいタブで開きます（作っている様子も画面に流れます）。そのまま Zoom で画面共有して見せられます。
- **Code用の指示文をコピー**：Claude Code にそのまま貼れる指示文を作ります。Googleカレンダー連携など「本物」を作るときに使います。

```
Zoom の音声（相手） ─┐
                      ├→ 話の区切りごとに OpenAI で文字起こし（数秒遅れで表示）
自分のマイク（自分） ─┘
          ↓ 90秒ごと（または「今すぐ分析」）
  相手の課題とツール案のカード ── たかさんが判断
          ├→ デモを自動生成（ダミーデータで動くHTML）
          └→ Claude Code 用の指示文
```

## 必要なもの

- Mac（macOS 14.2 以降）と最新の Google Chrome
- Node.js 20.6 以降（https://nodejs.org/ja から LTS 版をインストール）
- OpenAI の API キー（https://platform.openai.com/api-keys ）
- **ヘッドホンかイヤホン**（スピーカーだと相手の声をマイクが拾い、「自分」の発言として二重に入ります）

## はじめての準備（1回だけ）

```bash
cd meeting-assistant
cp .env.example .env
# .env を開いて OPENAI_API_KEY=sk-... に自分のキーを貼る
```

Mac の「システム設定 → プライバシーとセキュリティ → 画面とシステムオーディオ録音」で Google Chrome をオンにしてください（初回に聞かれたときに許可してもOK）。

## 商談での使い方

1. ターミナルで起動する
   ```bash
   cd meeting-assistant
   npm start
   ```
   「[モデル確認] … で動作します」と出ればOKです。モデル名のエラーが出たら、表示された候補から `.env` の `CHAT_MODEL` を書き換えてください。
2. Chrome で http://localhost:3939 を開く
3. Zoom の商談が始まったら「録音を開始」を押す
   - マイクの許可 → 「許可」
   - 共有画面の選択 → **「画面全体」タブを選び、「システム音声も共有する」をオン** にして共有
   - 右上の「相手」「自分」のメーターが声に合わせて動けば成功です
4. 相手が困りごとを話すと、右側にツール案のカードが出ます（デスクトップ通知も出ます）
5. 作りたいカードの「追加の指示」に一言足して（任意）、ボタンを押す
6. できたデモのタブを Zoom で画面共有して見せる
7. 終わったら「終了」→「保存」で、文字起こしとツール案を Markdown で保存

録音しなくても、「サンプル会話」ボタンで分析とデモ生成を試せます。商談前の練習にどうぞ。

> 商談の最初に「議事録用にAIで文字起こしをしています」と一言伝えておくのがおすすめです。

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「相手の音声を取り込めていません」と出る | 共有画面の選択で「画面全体」を選び、「システム音声も共有する」をオンにする。Chrome と macOS を最新にする |
| 相手の声が「自分」にも入る | ヘッドホンを使う |
| 聞き取れなかった | 下の入力欄から手入力で補えます |
| デモがイマイチ | 「追加の指示」に直してほしい点を書いて、もう一度「デモを自動生成」 |

## 設定（.env）

| 項目 | 内容 |
|---|---|
| `OPENAI_API_KEY` | OpenAI の API キー |
| `TRANSCRIBE_MODEL` | 文字起こしモデル（既定：`gpt-4o-transcribe`） |
| `CHAT_MODEL` | 分析・デモ生成のモデル（既定：`gpt-5.5`） |
| `REASONING_EFFORT` | `low` / `medium` / `high`。速さ優先なら `low`。推論モデル以外を使うときは空にする |
| `PORT` | ポート番号（既定：3939） |

## 補足

- サーバーは自分のPC（localhost）からしかアクセスできません。APIキーがブラウザに渡ることもありません。
- 作ったデモは `generated/` に保存されます。相手に URL で送りたい場合は、指示文ボタンから Claude Code で本番版を作るか、HTML を Claude のアーティファクトなどで公開してください。
- 文字起こしは「話の区切り（無音）」ごとに送るため、数秒〜15秒ほど遅れて表示されます。
